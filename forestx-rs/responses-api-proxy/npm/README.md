# @openai/forestx-responses-api-proxy

<p align="center"><code>npm i -g @openai/forestx-responses-api-proxy</code> to install <code>forestx-responses-api-proxy</code></p>

This package distributes the prebuilt [Forestx Responses API proxy binary](https://github.com/openai/forestx/tree/main/forestx-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/forestx-responses-api-proxy.js --help
```

Refer to [`forestx-rs/responses-api-proxy/README.md`](https://github.com/openai/forestx/blob/main/forestx-rs/responses-api-proxy/README.md) for detailed documentation.
